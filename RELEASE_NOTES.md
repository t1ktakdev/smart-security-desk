# Smart Security Desk v1.0.0

Первый учебный MVP: 8 Express REST endpoints, JSON-персистентность, валидация, адаптивный Dashboard, камеры, IoT-события, инциденты, фильтры, опциональный реальный MediaMTX preview, автоматические и негативные тесты.

Исправление: PATCH incidents отклоняет status=closed, неизвестные и read-only поля; переходы new -> in_progress -> resolved.

Все исходные события обозначены DEMO. Для промышленного использования необходимы авторизация, журнал аудита, HTTPS и полноценная БД.
